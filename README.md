# ВТБ Оракул Доверия

```sh
docker compose up --build -d --wait # поднять сайт
docker compose run --rm demo # смоделировать подтверждение 4 единиц данных и отправки денег продавцу
docker compose run --rm settle-demo # смоделировать погашение долга покупателем
```

Модули:
- `backend` — API, проверка данных и подпись оракула.
- `frontend` — панель управления.
- `contracts` — смарт-контракты факторинга и тестового рубля.
- `config` — источники, правила и формат подтверждений.
- `scripts` — развёртывание и демо.
